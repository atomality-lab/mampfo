# Update von Mampfo v0.6.3 auf v0.6.4

## Dateien aktualisieren

Kopiere die Dateien aus diesem Paket über die entsprechenden Dateien deines GitHub-Repositories.

**Wichtig:** Dieses Paket enthält absichtlich weder `supabase-config.js` noch `SUPABASE_SETUP.sql`. Deine bereits funktionierende Supabase-Konfiguration bleibt dadurch unverändert.

Eine SQL-Migration ist für v0.6.4 nicht erforderlich.

## Danach

1. GitHub-Pages-Deployment abwarten.
2. Mampfo einmal hart neu laden bzw. die installierte PWA vollständig schließen und erneut öffnen.
3. Unter **Einstellungen → Datenaustausch** sollte **Version 0.6.4** sichtbar sein.
4. Prüfe den neuen Statusblock und führe einmal **Jetzt synchronisieren** aus.
5. Optional kannst du diesem Gerät über **Umbenennen** einen eigenen Namen geben.

Bestehende lokale Daten, Supabase-Daten, Konflikte, Baselines und Rücksprungpunkte bleiben erhalten.
