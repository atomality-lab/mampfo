# Update von Mampfo v0.7.2.2 auf v0.7.2.3

1. Die Dateien aus dem v0.7.2.3-Paket in das bestehende GitHub-Repository übernehmen.
2. Die vorhandene `supabase-config.js` im Repository **nicht löschen oder überschreiben**. Sie ist bewusst nicht im Update-Paket enthalten.
3. Es sind **keine SQL-Änderungen** in Supabase erforderlich.
4. GitHub Pages vollständig deployen lassen und Mampfo anschließend hart neu laden bzw. die installierte PWA einmal vollständig schließen und neu öffnen.
5. Unter **Einstellungen → Datenaustausch** prüfen. Bei quantitativ und strukturell gleichem Stand sollte nach einem erfolgreichen Sync **Alles aktuell** angezeigt werden.

Der Patch verändert keine Ernährungs-, Lebensmittel-, Rezept- oder Fastendaten.
