# Update Mampfo v0.7.2.3 → v0.7.2.4

1. Die Dateien aus dem v0.7.2.4-Paket über die bestehenden Repository-Dateien kopieren.
2. Die vorhandene `supabase-config.js` **nicht löschen oder überschreiben**. Sie ist nicht im Paket enthalten.
3. GitHub Pages veröffentlichen lassen und Mampfo anschließend hart neu laden bzw. die installierte PWA vollständig schließen und neu öffnen.
4. Unter **Einstellungen → Datenaustausch** einmal **Jetzt synchronisieren** ausführen.
5. Wenn lokale und Cloud-Daten bereits identisch sind, sollte der Status anschließend dauerhaft **Alles aktuell** anzeigen.

Es ist keine Änderung an der Supabase-Datenbank erforderlich.
